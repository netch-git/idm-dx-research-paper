企業規模と組織階層がDX推進意識および組織摩擦認知に及ぼす影響：2,035名の就業者データに基づく二元配置分散分析と階層乖離ダイナミクス

著者: IDM デジタル変革調査研究グループ 日付: 2026年10月6日（真正完全版） 査読対応完成論文 (Type II ANOVA) 有効標本数 N = 2,035
要約 (Abstract)

本研究は、日本国内の就業者2,035名を対象とした全量データに基づき、企業規模（大企業 n = 745 名 vs 中小企業 n = 1,290 名）および組織階層（経営層 n = 329 名、部課長クラス n = 806 名、一般社員 n = 900 名）が、DXに対する推進意識・心理的所有感（SC18合成スコア、9項目、α = 0.859）およびDXに伴うリスク懸念・組織摩擦認知（SC15合成スコア、9項目、α = 0.818）に及ぼす影響を二元配置分散分析（Type II ANOVA）および層別単純主効果検定により厳密に検証した。

分析の結果、DX推進意識（SC18）においては、企業規模主効果（F(1, 2029) = 8.04, p = 0.0046, ηp2 = 0.0039）、職制主効果（F(2, 2029) = 38.58, p = 3.60 × 10−17, ηp2 = 0.0366）、および交互作用効果（F(2, 2029) = 4.32, p = 0.0134, ηp2 = 0.0042）のすべてが統計的に有意であった。単純主効果分析により、経営層（大企業 M = 3.77 vs 中小 M = 3.48, p = 0.0200, g = 0.44）および部課長クラス（大企業 M = 3.37 vs 中小 M = 3.22, p = 0.0010, g = 0.24）では大企業が有意に高い推進意識を示す一方、一般社員層では企業規模による有意差が完全に消失し（大企業 M = 3.18 vs 中小 M = 3.18, p = 0.9032, g = 0.01）、現場の意識が低位収束している実態（現場収束現象）が明らかとなった。

さらに補完的従属変数である組織摩擦認知（SC15）においては、規模主効果は有意でなかったが（F(1, 2029) = 1.97, p = 0.1601, ηp2 = 0.0010）、職制主効果（F(2, 2029) = 61.98, p = 7.44 × 10−27, ηp2 = 0.0576）と交互作用効果（F(2, 2029) = 5.79, p = 0.0031, ηp2 = 0.0057）が極めて顕著に有意であった。特筆すべきは中小企業における階層乖離であり、中小企業の経営層はリスク・摩擦認知が極端に低い（M = 2.69）のに対し、部課長クラス（M = 3.10）および一般社員（M = 3.18）は高い摩擦を認知しており（経営層との乖離 p < 0.001, g = 0.79）、経営層の過度な楽観主義バイアスと現場の負担感との間に深刻な構造的断絶が存在することが実証された。また、推進意識と摩擦認知の相関は r = −0.0901（p < 0.001）と微弱であり、両者が心理的に独立した直交次元を形成していることが示された。

キーワード: デジタルトランスフォーメーション (DX), 企業規模, 職制グループ, 二元配置分散分析, 心理的所有感, 組織摩擦, 現場収束現象, 直交ダイナミクス

1. 序論 (Introduction)

デジタル技術を活用した業務プロセスの変革やビジネスモデルの再構築を目指すデジタルトランスフォーメーション（Digital Transformation: DX）は、企業の持続的競争優位性を左右する最重要経営課題となっている（Kane et al., 2015）。しかし、多くの組織においてDX推進は順調に進展しておらず、経済産業省が警鐘を鳴らす「2025年の崖」問題や組織内の抵抗に直面している。先行研究は、DXの成否を決定づける要因として、単なる技術導入の多寡にとどまらず、組織構成員の変革受容性、推進意識、および組織内摩擦のマネジメントが不可欠であることを示唆している（Papadopoulos et al., 2020）。

特に、企業規模（大企業 vs 中小企業）と組織階層（経営層、管理職層、一般社員層）がDX認識に及ぼす影響については、理論的に強い関心が寄せられている。大企業は豊富な資金・人材リソースを背景にDXを戦略的に推進する体制を整えやすい一方で、組織の階層性や官僚主義が現場への浸透を阻害する可能性がある。対照的に、中小企業（SMEs）は機動性や経営者のリーダーシップが直接的に組織を動かす力を持つ反面、デジタル投資余力や専門人材の不足という構造的制約を抱えている（Eller et al., 2020; Garzoni et al., 2020）。

さらに、組織内の「階層（職制）」による視点の相違は、DX推進における致命的な摩擦を生み出す要因となる。経営層がデジタル変革を自社の将来戦略として捉える一方で、実務の変革を直接担う部課長クラスはリソース配分や業務負荷の増大に直面し、一般社員は雇用の安定性や既存スキルの陳腐化に対する懸念を抱きやすい。

先行研究の多くは、定性的な事例分析や、特定の階層（主に経営者やIT担当役員）のみを対象としたアンケート調査に依存しており、同一組織コンテキストにおける企業規模と複数階層の「交差（交互作用）」を全量統計的に検証した実証知見は極めて乏しい。本研究では、国内2,035名の就業者から得られたマイクロデータを対象とし、企業規模（2水準）と職制（3水準）の要因配置に基づく二元配置分散分析（Two-Way ANOVA）を実行することで、以下のリサーチ・クエスチョン（RQ）を解明することを目的とする。

  • RQ1: DX推進意識・心理的所有感（SC18）において、企業規模および組織階層による主効果、ならびに両者の交互作用効果が存在するか。
  • RQ2: DXに伴うリスク懸念・組織摩擦認知（SC15）において、企業規模および組織階層による差異はどのように発現し、推進意識とどのように連動しているか。
  • RQ3: 大企業と中小企業において、階層間の認識乖離パターンにはどのような構造的特異性が見られるか。

2. 文献レビューと仮説構築 (Literature Review & Hypotheses)

2.1 企業規模とDX推進（大企業 vs 中小企業）

組織能力論および資源依拠観点（RBV）において、デジタル変革は組織の吸収能力（Absorptive Capacity）と動的能力に依存する。大企業は体系的なリスキリングプログラムを展開する資源余力を有するため、全体的なDX推進意識が高まりやすい。一方で中小企業の実証研究において、Omrani et al. (2024) はEU域内15,346社の中小企業データを分析し、TOE枠組み（技術・組織・環境）に基づきITインフラや既存の革新水準がDX推進の決定的要因であることを立証している。また、AlNuaimi et al. (2022) は組織のアジリティ（敏捷性）とデジタル戦略の整合におけるリーダーシップの決定的役割を論じ、経営層のコミットメントの重要性を強調している。さらに、日本企業の実態調査として Liu et al. (2021) は、製薬企業営業部門におけるDX推進課題を分析し、現場部門が直面する特有の組織摩擦を報告している。しかし、現場レベルにおいてはデジタルツール導入に伴う初期負担や業務プロセスの混乱に対する耐性が大企業よりも低いため、組織全体としての一体感を維持することは容易ではない（Roman & Rusu, 2022）。

2.2 組織階層と心理的所有感・組織摩擦

心理的所有感理論（Psychological Ownership Theory; Pierce et al., 2001）によれば、個人が変革対象に対して「自己の目標」「我々の組織の将来」としての所有感を抱くとき、変革への積極的参画が促進される。経営層は変革の決定権を有するため最も高い心理的所有感を持つが、現場社員は受動的な業務変更を強いられるため、所有感は階層が下降するにつれて低下することが予測される。同時に、組織変革に伴うリスクや摩擦（SC15）の認知に関しても、Packmohr et al. (2023) は大企業と中小企業におけるDX推進障壁の認知差を分析し、階層や企業規模によって直面する障壁の種類（技術的、組織的、心理的）が明確に分化することを示した。また、データ駆動型DXにおいては単なる技術導入を超えた組織文化の変革が不可欠であり、文化的な受容基盤が欠如している場合、現場の心理的抵抗が激化することが指摘されている（Ghafoori et al., 2024）。

2.3 仮説の設定

  • 仮説1（推進意識の規模主効果）: DX推進意識・心理的所有感（SC18）は、大企業が中小企業よりも有意に高い。
  • 仮説2（推進意識の職制主効果）: DX推進意識・心理的所有感（SC18）は、経営層、部課長クラス、一般社員の順に有意に低下する。
  • 仮説3（推進意識の交互作用効果）: 企業規模と職制グループの間に交互作用が存在し、大企業と中小企業の差は上位階層ほど大きく、一般社員層では収束する。
  • 仮説4（摩擦認知の職制主効果と交互作用）: DXリスク懸念・組織摩擦認知（SC15）は階層間で有意に異なり、特に中小企業において経営層と現場管理職・一般社員との間の認識乖離が大企業よりも顕著に拡大する。

3. 研究方法 (Methodology)

3.1 調査設計と対象地域の選定

本研究の実証データは、提携モニターを対象としたクローズド方式のインターネット調査（実査：株式会社サーベイリサーチセンター）により収集された。
調査対象は、日本国内の特定地域（北海道、宮城、東京、愛知、大阪、広島、福岡、熊本の8地域）に所在する民間企業に勤務する「経営者」「管理職」「一般職」である。対象地域の選定にあたっては、IT人材の流動性や都市規模を考慮し、各地方の主要中枢都市（札幌、仙台、東京、名古屋、大阪、広島、福岡）に加えて、半導体産業の急速な集積により産業構造および就業環境の変革が著しい熊本県を抽出対象として加えた。

3.2 サンプリング手続きと回収割付

1. 調査期間: 令和7年（2025年）11月20日 〜 11月25日
2. 有効回答数: スクリーニング調査有効回答 8,274サンプル → 本調査有効回答 2,035サンプル
3. 抽出条件: スクリーニング調査において、勤務先が「DXに取り組んでいる」と回答した就業者層を厳格に抽出した。
4. 回収割付: 組織内の職階間における認識乖離を解明するため、「経営者（役員・取締役・社長、 n = 329 名、16.2%）」「管理職（部課長クラス、 n = 806 名、39.6%）」「一般職（一般社員、 n = 900 名、44.2%）」の3区分で均等割付を志向した層化抽出を実施した。さらに、厚生労働省「賃金構造基本統計調査」の基準に準拠し、常用労働者1,000人以上を「大企業（Large, n = 745 名、36.6%）」、1,000人未満を「SMO（Small and Medium Organization：中小組織, n = 1,290 名、63.4%）」と定義した。

3.3 データ品質管理と研究上の配慮

Web調査システムの論理チェックおよび必須回答制御により、本調査完了データセット（N = 2,035）内には項目無回答や欠損値（Missing Values）は一切存在しない（完全決定論的データセット）。調査会社のデータクレンジング段階において、全設問同一選択肢回答（Straight-lining）や異常な短時間回答者（Speeders）は事前に検知・排除された。
本調査は人を対象とする非侵襲的な意識調査であり、調査会社（サーベイリサーチセンター）のモニター規約に基づき個人を特定可能な情報は収集されず、完全匿名化された統計データとして集計・解析された。また、回答者は調査会社の事前登録規約および調査画面における趣旨明示に基づき、自発的な意志によって回答を行った。

3.4 変数定義と測定尺度

1. DX推進意識・心理的所有感（SC18, 9項目）: 自社のDXに対する当事者意識、競争力強化への期待、推進コミットメント等を測定する9項目（1: 全くそう思わない 〜 5: 非常にそう思うの5点リッカート尺度）の算術平均値。
2. DXリスク懸念・組織摩擦認知（SC15, 9項目）: 新技術導入に伴う業務負荷増加、既存業務との軋轢、現場の孤立感、成果還元の不透明感等を測定する9項目（同5点リッカート尺度）の算術平均値。
3. 理論的背景：組織的公正（分配的公正）: Colquitt (2001) の組織的公正理論に基づき、DXに伴う学習負荷や業務変革に対して昇給や賞与といった適切な成果還元が期待できない状況（分配的公正の欠如）が一般職の心理的離反を招く背景要因として位置付けられる。

3.5 尺度信頼性と概念の直交性検証

クロンバックの α 係数による内的整合性の検証において、**SC18（DX推進意識）** は α = 0.8592（k = 9, N = 2,035, CITC: 0.392 〜 0.651）、**SC15（DX摩擦認知）** は α = 0.8183（k = 9, N = 2,035, CITC: 0.419 〜 0.595）といずれも高い信頼基準を満たした。SC18とSC15の相関係数は r = −0.0901（p = 4.66 × 10−5, r2 = 0.0081）と微弱であり、両尺度が直交する独立した心理動機構成概念であることが実証的に確認された。

3.6 統計分析モデル

不均等セル頻度に対応するため、Type II 平方和（Type II Sum of Squares）による二元配置分散分析（Two-Way ANOVA）を実行した。効果量として偏イータ二乗（ηp2）を算出した。HC3異分散頑健標準誤差による感度分析およびBrown-Forsythe検定を実施し、事後検定としてテューキーのHSD検定、ならびにウェルチの t 検定（Holm法多重性調整）による層別単純主効果検定を実施した。

5. 考察 (Discussion)

5.1 理論的示唆 (Theoretical Implications)

第1に、「属性規定性よりも階層規定性の優位」と「現場収束現象」の立証である。効果量の比較から、企業規模単独の効果量（ηp2 = 0.0039）よりも職制グループの効果量（ηp2 = 0.0366 〜 0.0576）が約9〜15倍大きく、DX意識を決定づける主因は「企業規模」ではなく「組織内の階層位置」であることが実証された。さらに、大企業の優位性が現場の一般社員層においては完全に同一水準（大企業 3.18 vs 中小 3.18, g = 0.01）に収束した。これは、先行研究が前提としてきた「大企業先進・中小企業遅延」というマクロな二元論（Eller et al., 2020; Garzoni et al., 2020）を精緻化するものである。どれほど大企業が資金やインフラを投入しても、末端の従業員に対する心理的所有感の移転（Ownership Transfer; Pierce et al., 2001）に失敗している現実を露呈している。

第2に、中小企業における「経営層の楽観主義バイアスと現場孤立」の解明である。中小企業において、経営層の組織摩擦認知は 2.69 と異常に低く、現場社員（3.18）との間に g = 0.79 もの巨大な認知断絶が存在した。Packmohr et al. (2023) が指摘するように、企業変革における阻害要因の認知差において、経営層はデジタル導入の戦略的果実を強調するあまり、現場が抱える既存業務の負荷や操作習熟の苦痛（Learning Curve Friction）を過小評価する「認知的盲点（Cognitive Blindspot）」に陥りやすい。中小企業の現場管理職や一般社員は、経営者直下のトップダウン圧力に晒されながらも代替リソースを与えられないため、大企業現場と同等以上の疲弊感と摩擦を抱え込んでいる。

第3に、DX意識の「二次元直交性（Orthogonal Dynamic）」の解明である。SC18とSC15の相関が r = −0.0901 と微弱であった事実は、Higgins (1997) の制御焦点理論が示すように、独立した二つの認知動機システムとして併存していることを強く示唆している。すなわち、「DXに強い意欲を持ちながらも、現場の摩擦を同時に強く懸念する」という心理状態が一般的であり、摩擦を無視した推進論は組織崩壊を招く危険性がある。

5.2 実務的示唆 (Practical Implications)

1. 中小企業経営者への警鐘：現場の「見えない摩擦」の可視化と組織文化の醸成
中小企業の経営者は、自らが主導するDXに対して現場が強い摩擦（3.18）を感じている事実を直視しなければならない。Ghafoori et al. (2024) や Succurro (2026) が実証するように、DXの定着には単なるツールの導入ではなく、戦略的計画の明文化とデータ駆動型組織文化の醸成が不可欠である。

2. 大企業における現場社員の「心理的所有感」の再設計とビジネスモデル変革
大企業においては、部課長から一般社員への「意識の目詰まり」が最大のボトルネックとなっている。各事業部の現場社員が小さな改善アイデアを自ら提案・実装する「ボトムアップ型ローコード開発」を奨励し、Pierce et al. (2001) の「対象への自己投資」の機会を提供する必要がある。さらに、Lamperti et al. (2024) が提示するように、現場が主体となって既存の製品・業務をサービス化するサービタイゼーションへの移行を促すことが有効である。

3. 中間管理職（部課長クラス）のバッファー機能の強化
両規模ともに部課長クラスは、上層部からの推進圧力と現場からの抵抗・不満の板挟みとなっている。管理職層に対してDX評価指標（KPI）を成果直結型だけでなく「現場の変革適応度」にも配分し、心理的安全性を担保したチェンジマネジメント研修を実施すべきである。

6. 結論と研究の限界 (Conclusion & Limitations)

6.1 結論

本研究は、2,035名の就業者全量データを用い、企業規模と組織階層がDX推進意識（SC18）および組織摩擦認知（SC15）に及ぼす影響を実証的に検証した。主要な知見として、(1) DX推進意識において企業規模と職制の有意な交互作用が確認され、大企業優位は上位層に限られ一般社員層では完全に低位収束すること、(2) 組織摩擦認知において中小企業の経営層（2.69）と現場層（3.10〜3.18）との間に g = 0.79 に達する深刻な認知乖離が存在すること、を統計的に立証した。これらの知見は、DXを単なる技術導入ではなく、組織階層間の認識統合と心理的所有感の再構築プロセスとして捉え直す重要性を強く要請している。

6.2 研究の限界と今後の課題 (Limitations & Future Research)

本研究には、結果の解釈において留意すべき以下の学術的限界が存在する。
第1に、横断的調査デザイン（Cross-Sectional Survey Design）に伴う因果推論の限界である。本研究は同一時点での観測データに基づくため、変数間の共変関係および交互作用の存在は厳密に実証されたものの、厳密な時間的先行性や直接的な因果関係（Causality）を断定することはできない。例えば、中小企業経営層の低摩擦認知が現場の孤立を招いているのか、あるいは現場の摩擦激化から経営層が無意識に目を背けているのかといった双方向的・動態的な影響関係を確定するためには、複数時点にわたる縦断的パネル調査（Longitudinal Panel Design）や介入実験による検証が不可欠である。
第2に、自己申告式データに伴う共通方法バイアス（Common Method Bias: CMB）の検証である。本調査では設問群の物理的分離（SC15とSC18の別ブロック提示）およびアンカーの多角化により手続的統制を図っており、実証的にもSC18とSC15の相関が極めて低い（r = −0.0901, r2 < 1%）ことから、単一の回答傾向による系統的歪み（ハロー効果や社会的望ましさバイアス）は極めて軽微であると判断される。
第3に、大企業経営層の標本サイズ（n = 31）は統計的検定力を維持しているものの、中小企業経営層（n = 298）と比較して相対的に小さいため、大規模企業特有のトップマネジメント層の細分化（CIO, CDO, 現場役員）を考慮したさらなる標本拡充が望まれる。今後は、業種別（製造、サービス、IT等）の統制変数を含めた多層モデル（Hierarchical Linear Modeling）による精緻な検証が期待される。

コラム 1: 二元配置分散分析（Two-Way ANOVA）って何？

基礎概念の直感理解

「企業規模」と「役職」を別々に調べず、なぜ同時に分析しなければならないのか？

統計学でよく使われる t 検定は「大企業と中小企業」など2つのグループの平均値の差を比べる手法です。しかし、現実の組織では「大企業か中小企業か」という看板（企業規模）と、「社長か平社員か」という立場（職制）が複雑に絡み合っています。

🍜 日常のたとえ：ラーメンの「スープ」と「麺の太さ」
「濃厚豚骨スープ」と「あっさり醤油スープ」の美味しさを比べるとき、合わせる麺が「極太ちぢれ麺」か「極細ストレート麺」かによって、スープの評価はガラリと変わります。スープ単独（主効果1）や麺単独（主効果2）だけでなく、「スープ×麺の組み合わせ（交互作用）」を同時に見なければ、本当の味（DX推進意欲）は分かりません！

本論文の二元配置分散分析（Type II ANOVA）は、企業規模の効果と役職の効果をきれいに分離した上で、「掛け合わせによる化学変化（交互作用）」を数学的に証明したのです。

コラム 2: なぜ「p 値」だけでは不十分なのか？ 〜効果量（η²p, Hedges' g）の歴史と威力〜

科学的健全性の歴史

「p < 0.05（有意差あり）」が出たからといって、大喜びしてはいけない理由。

統計検定における p 値は、「偶然その差が生じる確率」を表します。しかし、p 値には致命的な弱点があります。それは「サンプル数（N）が数千人規模に増えると、ほんの爪の先ほどの些細な差でも p < 0.001 になってしまう」という「大標本の罠」です。

💊 日常のたとえ：風邪薬の効き目
10万人に薬を飲ませたら、「熱が下がる時間が平均3秒早くなった」とします。サンプル数が巨大なので統計的には「p < 0.0001で確実に差がある（有意！）」となりますが、患者にとって3秒早く熱が下がることには何の意味もありません。本当に知りたいのは「実質的にどれくらいガツンと効いたか（効果の大きさ）」です。

この「実質的なインパクト」を測る指標が効果量（偏イータ二乗 ηp2 や Hedges' g）です。アメリカ心理学会（APA）は現在、論文投稿時に効果量の明記を義務付けています。本研究では、企業規模のインパクト（ηp2 = 0.0039）に対して、組織階層のインパクト（ηp2 = 0.0576）が約15倍も巨大であることを効果量によって科学的に暴き出しました。

コラム 3: 「現場収束現象」の衝撃 〜大企業の看板は現場でなぜ消えるのか？〜

本研究の核心的発見

社長同士には圧倒的な意識の差があるのに、なぜ一般社員は3.18で完全に一致したのか？

世間では「大企業はDXが進んでいて、中小企業は遅れている」と信じ込まれています。確かに経営層を見ると、大企業経営層は 3.77、中小企業経営層は 3.48 と大企業が圧勝しています。部課長クラスでも大企業が優位です。

しかし、最前線の一般社員層を見ると、大企業一般社員 3.18 vs 中小企業一般社員 3.18 で小数点第二位まで完全に同一水準でした（p = 0.9032, g = 0.01、差は完全にゼロ！）。

⚾ 日常のたとえ：名門プロ球団と地方独立リーグのルーキー
名門ジャイアンツの球団社長と、地方独立リーグの球団社長では、資金力もビジョンも桁違いです。しかし、入団したばかりの高卒新入団選手がグラウンドの隅で筋トレに励むとき、抱く不安や練習のしんどさは、名門球団だろうが地方球団だろうが全く同じです。

どれほど大企業が莫大なIT予算やDXコンサルを投じても、末端の従業員が「これは自分たちの仕事のためのツールだ」という当事者意識（心理的所有感）を持てなければ、現場の意識は中小企業と完全に同じレベルに沈み込んでしまうのです。

コラム 4: 二次元直交性（無相関）の直感理解 〜アクセルとブレーキは別のペダル〜

心理動機の二次元構造

「DXを進めたい気持ち」と「現場の摩擦を心配する気持ち」は、反対語ではない！

直感的には、「DXに意欲的な人ほど、組織の摩擦なんて気にしない（負の強い相関）」と思われがちです。しかし、2,035名のデータを分析した結果、DX推進意欲（SC18）と組織摩擦懸念（SC15）の相関係数はわずか r = −0.0901（ほぼ無相関）でした。

🚗 日常のたとえ：車の「アクセル」と「ブレーキ」
アクセルを強く踏むこと（前に進みたい意欲）と、ブレーキペダルの効き具合を気にかけること（事故を起こしたくない危機感）は、別のメカニズムです。「目的地に早く着きたい！」と強く願いながらも、「道が凍結しているからスリップが怖い！」と同時に強く警戒することは極めて自然な人間の心理です。

心理学者ヒギンズの「制御焦点理論（Higgins, 1997）」が示す通り、人間にはチャンスを求める動機（促進焦点）と、失敗を避ける動機（予防焦点）が独立して同居しています。現場が「摩擦が不安だ」と訴えているとき、それはDXに反対しているのではなく、「ブレーキの安全性を確認している」に過ぎないのです。
