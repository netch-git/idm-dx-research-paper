# Agent Localization Skill: Full Japanese

## 概要
Antigravity環境において、AIが生成するすべての説明テキスト、内部ログ、タスク管理、コードコメント、コミットメッセージを日本語で統一・制御するスキルです。

## 指示・制約事項

### 1. ユーザーインターフェース・対話
- ユーザーに対するすべての返答、説明、要約、確認の問いかけは、正確かつ自然な日本語で行うこと。
- 英語での入力を受け取った場合でも、明示的な英語指定がない限り日本語で解説・回答すること。

### 2. 思考プロセスとアーティファクト
- タスク分解（Todoリスト）、アーキテクチャ設計書、実装ステップの提示は日本語で記述すること。
- エラー分析やデバッグの進捗報告も日本語で整理して提示すること。

### 3. ソースコードおよび開発関連テキスト
- **コード内コメント**: 処理概要、引数・戻り値の説明、注意点はすべて日本語で記述する。
- **命名規則**: クラス、関数、変数名は一般的な英単語を使用し、ローマ字表記は避ける。
- **コミットメッセージ**: Conventional Commitsに準拠し、コミット概要は日本語とする（例: `refactor: データ抽出ロジックのリファクタリング`）。

### 4. 精度維持・検証ルール
- 日本語でのやり取りにおいても、架空のAPIや存在しないライブラリを捏造（ハルシネーション）しないこと。
- ファイルパスや既存コードの仕様は、必ず実環境のファイルを探索・確認してから日本語で説明すること。
