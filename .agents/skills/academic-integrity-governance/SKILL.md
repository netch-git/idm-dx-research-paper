# Academic Integrity & Zero-Fabrication Governance Skill

## 1. 目的と適用範囲
本スキルは、学術論文、研究報告、発表資料の作成において、AIエージェントによる**事実の無断補完（捏造挿入）**および**架空文献の引用（文献捏造）**を機械的・決定論的に根絶するための最上位プロトコルを定めます。

---

## 2. 調査手法・データ記述の完全拘束規程（Zero-Assumption Protocol）

### 2.1 一次資料外の推測加筆の絶対禁止
- 調査手法（Research Design）、標本抽出（Sampling）、データ品質管理（Data Cleaning）、倫理審査・インフォームドコンセント（Ethics & Consent）に関する記述は、**ユーザーから提供された一次資料（PDF本文、元データ、公式台帳）に文字通り記載されている事実のみ**を出典として記述すること。
- 「一般的なWeb調査会社ではこうしているはずだ」「査読を通すためにはこの記述が必要だ」という推測・業界慣行を、本研究の事実として書き加えること（例: ヘルシンキ宣言準拠、スピード回答除外、ストレートライン検知等）を永久に厳禁とする。

### 2.2 未記載事項の申告義務（No Implicit Completion）
- 学術誌の査読要件上必要とされる項目であっても、一次資料に記載がない場合は、AIが勝手に作文・穴埋めすることを厳禁とする。
- 必ず「**※元資料に記載がありません。実際の調査実態についてご指示・ご確認をお願いします**」と明示してユーザーに確認を求めること。

---

## 3. 引用文献（References / Citations）の厳格な実在性検証規程

### 3.1 架空文献の完全禁止
- 生成AIの統計的言語モデルに依存した「もっともらしい著者名」「存在しない論文タイトル」「架空の掲載誌・巻号・DOI」の出力は、学術研究における致命的過失と定義し、完全に禁止する。

### 3.2 引用可能文献の厳格な3大基準
本文（インライン引用）および参考文献リストに記載できる文献は、以下のいずれかに該当するものに限定する：
1. **元論文・一次資料に明記されている文献**: ユーザー提供PDFの参考文献一覧に記載された文献。
2. **プロジェクト内検証済みマスター文献**: プロジェクト内でDOI照合・誌名照合が完了している確定文献（全20編マスター）。
3. **実在が完全検証された文献**: 新たに先行研究を引用する場合は、Web検索や公式学術データベース（Crossref, Google Scholar, PubMed, IEEE Xplore等）を用いて、著者名・出版年・論文名・掲載誌名・巻号・ページ・有効なDOIが実在することを確認した上で引用すること。

---

## 4. 出力前セルフチェックリスト（機械的監査プロトコル）

論文本文、章節ドラフト、参考文献を出力する直前に、エージェントは以下のチェックを必ず実行すること：

| 検査項目 | 合格基準 | 不合格時のアクション |
| :--- | :--- | :--- |
| **調査手法の事実性** | 一次資料（PDF本文）にない手続き（スピード除外・特定倫理宣言等）が含まれていないこと | 該当記述を即座に削除し、事実のみに修正 |
| **文献の実在性** | 引用されたすべての `Author (Year)` が実在し、DOIまたは確実な書誌情報が存在すること | 架空文献を削除し、実在する検証済み文献に差し替え |
| **文体・トーン** | 文学的修辞（警鐘を鳴らす、冷え込み等）や不要なカタカナ語（インプリケーション等）がゼロであること | 客観的・中立的な学術日本語に置換 |
| **数値の完全一致** | 本文中の統計数値（F値, p値, サンプル数等）が確定解析データ・出力JSONと100%一致していること | 動的バインドまたは元データから再抽出 |
